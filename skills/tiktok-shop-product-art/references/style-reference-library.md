# 视觉参考研究规则

目的不是拼凑“爆款”数据，而是找出可解释的视觉差异，给设计决策提供依据。

## 资料来源优先顺序
1. 用户提供的高质量商详、原品牌视觉规范、实拍风格样板。
2. 目标站点真实商品页面（必须实际看过图片才能评价构图）。
3. 适用于该商品的生活方式摄影、家居视觉灵感（只做风格学习）。

## 研究卡片（每条参考最多 7 行）
- 页面/图片链接：
- 目标市场、类目、查看日期：
- 页面是否实际可见：是 / 否 / 仅文字
- 可借鉴：主体占比、场景、主光、用色、镜头/构图、图组顺序
- 不应借鉴：版权图、虚假数量/尺寸、夸张功效、与本站规则冲突处
- 对当前商品的具体改动：

有 1 个真正合用的参考就先推进；2-3 个可提高风格判断。无法访问时写明“参考不可验证”并按 Visual DNA 继续。禁止写不存在的链接、销售额、转化率、排名或“业内最佳”结论。
