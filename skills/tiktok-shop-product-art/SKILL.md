# 跨境美工 v2.0

## 目标与优先级

目标：让买家 **先看清卖什么 → 想象放在自己家里的效果 → 核实材质尺寸与购买内容**。视觉品质要好，但不能以美观牺牲真实性和平台合规。

优先级（从高到低）：**真实商品与已证实信息 > 当前站点政策 > 用户明确要求 > 可辨识的场景表达 > 高级美感 > 批量效率**。发现冲突时按此排序裁决并简短记录。

**区分四种产物，严禁混称“主图”：**

- `GALLERY_PRIMARY`：商品图库第 1 张（首图），按站点首图规范制作。
- `GALLERY_SECONDARY`：商品图库第 2 至 N 张，展示实际商品的不同角度、真实场景、材质和尺寸。站点禁止的叠字/装饰不放进去。
- `DETAIL_CONTENT`：商品描述区的图文内容，可根据项目选择原创设计、供应商图优化、或混合模式。
- `SKU_VARIANT`：与实际可售 SKU 一一对应的变体图；不得用 AI 想象不存在的款式。

广告海报、投流封面、短视频封面归 `AD_CREATIVE`，单独制作，不混入商品图库；用户没有要求时无需生成。

## 运行模式

根据用户要求选择，无须每次都询问：

- `FULL_DESIGN`（默认）：从资料/实拍图开始策划图库与详情页，允许新设计背景、场景和版式，严格保留商品真实身份。
- `SOURCE_OPTIMIZE`：用户明确说“只修原图/只翻译/不改变版式”时，才局限于抠图、清理、色彩修正、翻译和确定性排版。
- `PLAN_ONLY`：用户只要策划、分镜或提示词时，只交可执行方案，不声称已生成成品。

当用户交给本 Skill 一个明确的完整制作任务，就连贯执行到可完成的交付阶段，不需对每个小决定反复征求批准；**涉及缺失且会改变商品事实的资料**才提出精确问题或用占位并阻止该图成为成品。

## 工作流

### 1. 素材审计（事实锁定）

列出来源图片/文件、可见商品与 SKU、可用角度、文字和 Logo 是否可辨。确认供应商素材使用授权；第三方水印不能在未确认权利时擅自去除。建立简要事实表：字段、值、证据、状态 `confirmed | visible | seller_claim | inferred | unknown`。

- 可上图作为产品承诺的内容须 `confirmed` 或可靠来源可验证；`seller_claim` 未核实时需谨慎且不得做夸大承诺；`inferred/unknown` 不写成事实。
- 不能改变或虚构：商品数量、尺寸、厚度、材质、颜色、印花/字样、商标、表面纹理、安装位置、配件、使用效果与性能。
- 用户提供的产品图是身份锚点。优先 **原商品抠图 + 场景摄影/生成背景 + 确定性排版**；不让模型从头重新绘制有文字/图案/复杂结构的商品。
- 缺少尺寸时仍可制作白底/近景图，但不得产出具有误导性的“真实安装比例图”；尺寸页标记 `BLOCKED` 而不是编数字。

### 2. 识别站点与规则

确定市场、目标语言、商品类目。优先检查该市场当下 TikTok Shop Seller Center 规则；检索失败时记录“待核实”，不得把美国站规则冒充全球通用规则。规则摘要参照 [references/market-policy.md](references/market-policy.md)。

美国站默认安全做法：首图纯白底、完整实际售卖商品、正面清楚展示；所有图库图片无新增文字、水印、边框、宣传贴纸。其余图可在不误导的前提下展示真实使用场景。图库建议 1:1，>=600×600，最多 9 张；导出时以实际站点规定为准。

### 3. 商品类型 → 场景策略

先判断 `WALL_DECAL`（墙贴/贴画）、`ORNAMENT`（摆件/桌面装饰）或 `GENERAL`。根据 [references/category-playbooks.md](references/category-playbooks.md) 确定商品在画面中如何出现、关键场景、适用限制、比例与买家疑虑。

编写不超过 12 行的 **Visual DNA**：目标买家/空间、真实商品证据、视觉风格关键词、主辅色、材料和环境质感、镜头与光线、商品主体占比、背景干扰边界、禁用元素、整组统一规则。

视觉判断优先于空洞风格词：明确“在哪个空间、什么材质的墙/家具、哪个镜头角度、光从哪里来、商品在画面哪里”。场景要适合销售价位和真实使用环境；不要把廉价小摆件变成巨型雕塑，也不要把小墙贴铺满整面墙。

### 4. 参考研究（不阻塞）

优先用户提供的商详与品牌参考；可以联网时再寻找同站点同类商品、室内摄影或家居风格参考，**1 至 3 个有用参考即可，质量优先于凑数**。记录 URL、日期、实际看过什么、学到什么与不可照搬之处。图无法打开要写“仅查到文字，不可验证视觉”。

不可查阅时继续使用 Visual DNA 与用户素材，标注“外部视觉参考未核验”，**不能卡死整个任务，也不能杜撰竞品或转化数据**。参考只借鉴构图、灯光、节奏，不复制版权图片/品牌资产。

更详细的研究方法见 [references/style-reference-library.md](references/style-reference-library.md)。

### 5. 先出分镜表，再出图

按信息功能列出每张图片的：`type / slot / buyer_question / exact_product_evidence / copy / scene / angle / reference / output_size / approval_status`。默认建议 **5 至 7 张图库图**，而不是不顾资料齐全程度强制凑数；最多不超过对应站点上限。详情页分模块规划，尺寸和长宽比以最终上传要求与阅读体验确定，不一律硬编码 9:16。

美国站场景依赖类商品推荐顺序：

1. `GALLERY_PRIMARY`：真实商品纯白底、正面清晰；墙贴可展示整套图案平铺，摆件可展示完整实体。
2. `GALLERY_SECONDARY`：最有吸引力的真实使用场景，墙贴在可信墙面位置，摆件在适当桌面/书架。
3. `GALLERY_SECONDARY`：第二空间或不同摄影角度，不要仅换背景复用同一透视。
4. `GALLERY_SECONDARY`：真实材质/图案/工艺特写。
5. `GALLERY_SECONDARY`：尺寸、套装、附件或安装使用展示，具体取决于已核实资料及站点允许的表现方式。
6-7. 如素材充分，补充其他有信息价值的角度、用途与内容，不重复填数。

详情页（`DETAIL_CONTENT`）优先 4 至 6 个模块：①真实空间效果与简短价值主张；②真实核心卖点；③细节与材质；④尺寸/覆盖范围/适用表面；⑤安装与维护/包装清单；⑥购买前注意事项（按商品选择）。**详情页不是只能修供应商原图**。可以原创场景、排版及文案，只要保留真实商品和来源事实；用户要求“仅优化”时例外。

### 6. 制作：背景可创作，商品不可幻觉

- 检查执行环境：有哪些图片编辑/生成工具可用，就使用哪些；缺少图片工具时交付策划/提示词/可编辑排版方案并明确说明，不能假装已出成品。
- 商品本体优先保持原图像素；必要时透视变换、色彩匹配、接触阴影/遮挡处理，但 **变换后图案、字样、边缘、厚度、颜色**仍要与实物一致。
- AI 适合生成不含商品的空间背景、光影构想、辅景或创意草图；精确尺寸、英文文案、符号、Logo 交给可控图形排版/合成工具。不要把 AI 重画商品当成事实依据。
- `WALL_DECAL`：检查粘贴面是否现实可用、贴纸与墙面透视是否一致、贴纸内容/方向/数量是否准确；不要暗示未知材质适用于瓷砖/玻璃/户外。
- `ORNAMENT`：接触阴影、尺度（参考书/台灯/桌面）、表面反射、实体厚度要可信，不凭空长出配件或多件商品。
- 每一张图库图的构图或信息任务不同；详情页标题不压商品，高对比、少文字、移动端可读。
- 尺寸/规格由结构化事实表驱动，不能仅凭图像模型“画一个尺子”。SKU 图应基于对应实物图或可验证的变体资料。

制作前可先完成 1 张首图 + 1 张最有代表性的场景图/详情模块，自检并修正共性问题，再批量出剩余内容。除非用户明确要求暂停审批，不要每做一步都停止。

具体设计准则见 [references/design-system.md](references/design-system.md)。

### 7. 双重质检，不达标重做

**硬性门禁（任一失败不可作为成品）：**市场合规、商品身份与数量、文案来源、SKU/配件映射、尺寸准确、错误/伪造 Logo 文本、误导性适用面与效果、导出规格。

**美学门禁（逐项 0/1/2 分，每项至少 1，合计目标 >=9/12）：**
1. 三秒内看懂卖什么；2. 商品与背景主次明确；3. 光影和空间透视自然；4. 风格配色协调；5. 文案层级与移动端可读；6. 整组构图有节奏而非重复。

不合格先调整相应设计变量（比如光位/主体大小/场景密度/字重），避免只反复追加“更高级、更精致”的空泛提示词。记录失败项与修复结果。规格和尺寸可运行 `scripts/validate_assets.py` 辅助检查，但该脚本 **不能代替** 事实、合规、视觉的人工/模型审阅。

### 8. 交付与上架协同

输出实际可用文件，不只给一堆提示词：

```
商品名/
  主图/         01_白底首图.png 02_客厅场景.png ...
  详情图/       01_场景开篇.png 02_材质细节.png ...
  SKU图/        01_对应SKU名称.png ...
  审阅资料/     visual-brief.md fact-ledger.csv storyboard.csv qa-report.md references.md README.md
```

为每个交付产物记录用途、顺序、实际文件名、SKU、来源事实和审核状态；必要时附 ZIP 和排序预览。不能生成的文件记入阻塞清单，不混入成品文件夹。**不要自行发布商品。**

当由 `miaoshou-tiktok-listing-pipeline` 调用时，先读取该项目实际共享契约，再生成它要求的 `miaoshou-upload-manifest.json`，保留文件 SHA-256、顺序、用途和精确 SKU 映射；**不得凭本 Skill 猜测外部流程的 JSON schema**。多语言翻译遵循已有审批文案、目标市场语言及对应语言审校 Skill，不私改事实。

## 异常处理

- **只有一张产品照片**：可合规白底、细节和基于原件抠图的场景合成；不伪造背面或另一种结构。标记缺少角度。
- **尺寸未知**：不得做可信尺寸示意与尺寸承诺；其余图可以继续。
- **参考无法访问**：明确记录后继续，不为了“研究满 3 家”无限等待。
- **工具无法准确保留商品细节**：退回到原像素抠图/叠图；仍无法做到则只出场景布局样稿，标记不可上架。
- **发现目标站点规则与本 Skill 摘要不一致**：以最新对应站点官方规则为准并记录日期。
